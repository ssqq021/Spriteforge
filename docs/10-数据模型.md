# 数据模型

## Project

```ts
type Project = {
  id: string;
  name: string;
  unityVersion: string;
  defaultFrameSize: number;
  defaultFps: number;
  createdAt: string;
  updatedAt: string;
};
```

## Character

```ts
type Character = {
  id: string;
  projectId: string;
  name: string;
  referenceAssetId?: string;
  tags: string[];
  defaultPivot: [number, number];
};
```

## Action

```ts
type CharacterAction = {
  id: string;
  characterId: string;
  name: string;
  direction: "south" | "north" | "east" | "west" | "none";
  fps: number;
  loop: boolean;
  frameIds: string[];
  activeVersionId: string;
};
```

## Frame

```ts
type Frame = {
  id: string;
  sourceAssetId: string;
  index: number;
  enabled: boolean;
  durationMs: number;
  crop?: Rect;
  transform?: {
    x: number;
    y: number;
    scale: number;
  };
};
```

## ProcessingVersion

- 输入资产
- 参数
- 算法版本
- 输出资产
- 创建时间
- 状态
- 错误信息

## ExportRecord

- 项目
- 角色
- 动作
- 版本
- 导出格式
- Schema 版本
- 文件列表
- 校验值
