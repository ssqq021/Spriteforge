# UI 设计规范

## 设计目标

界面应像专业生产工具，而不是营销型 AI 网站。

关键词：

- 清晰
- 高密度但不拥挤
- 参数可预测
- 状态明确
- 长时间使用不疲劳

## 布局

- 桌面端最小宽度：1280px
- 左侧导航：72px 折叠 / 220px 展开
- 顶部栏：56px
- 属性面板：280–360px
- 时间轴：最小 180px 高
- 核心画布自适应

## 中文字体

- Windows：Microsoft YaHei UI
- Web：`Inter, "Microsoft YaHei UI", "PingFang SC", sans-serif`

## 字号

- 页面标题：24
- 区块标题：16
- 正文：14
- 辅助文字：12
- 参数标签：12

## 颜色建议

- 主色：`#7446F5`
- 主色悬停：`#6235DD`
- 成功：`#22A06B`
- 警告：`#D98E04`
- 错误：`#D64545`
- 深色背景：`#11131A`
- 面板：`#1A1D27`
- 边框：`#303443`
- 浅色背景：`#F6F7FB`

## 组件规则

- 主操作每个页面最多一个
- 危险操作必须二次确认
- 开关用于即时生效的二元设置
- 复选框用于导出内容选择
- 所有数值输入支持键盘微调
- 处理前后对比必须支持拖动分割线
