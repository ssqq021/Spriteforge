# 产品需求文档（PRD）

## 1. 目标

建立一个项目化的角色资源工作流，承接现有媒体处理工具，并形成从素材导入到 Unity 导出的闭环。

## 2. MVP 用户故事

### US-01 新建项目

作为游戏开发者，我可以建立一个项目并定义目标 Unity 版本、默认帧尺寸、FPS 和命名规范。

### US-02 新建角色

我可以为角色设置名称、参考图、风格标签和默认 Pivot。

### US-03 导入动作

我可以从视频、GIF、图片序列或 SpriteSheet 导入一个动作。

### US-04 处理帧

我可以删除、启用、排序、复制和预览帧。

### US-05 清理背景

我可以选择去背景、去黑底或 Alpha 修边，并查看前后对比。

### US-06 统一帧

我可以统一画布、角色位置、缩放、边距和 Pivot。

### US-07 导出预览

我可以导出 GIF/WebP，用于检查动作循环和抖动。

### US-08 导出 Unity

我可以导出资源包和描述文件，Unity 插件能自动完成导入配置。

## 3. 页面范围

- 登录页（后置，MVP 可先本地使用）
- 首页
- 项目列表
- 项目详情
- 人物工作区
- 动作编辑器
- 序列帧编辑器
- AI 修图
- Unity 导出
- 任务记录
- 设置

## 4. 核心对象

```text
Project
└── Character
    ├── Reference
    ├── Action
    │   ├── Source
    │   ├── Frames
    │   ├── ProcessSettings
    │   └── ExportSettings
    └── UnityExportProfile
```

## 5. 功能优先级

### P0

- 项目和角色
- 视频/图片/GIF/SpriteSheet 导入
- 抽帧和筛帧
- SpriteSheet 生成
- GIF/WebP 预览
- Unity JSON + 插件导入
- 自动切片和 AnimationClip

### P1

- 透明背景处理
- 去黑边
- 自动裁切
- 角色位置稳定
- 动作循环
- 导出模板

### P2

- AI 动作生成
- 一致性
- 多方向补全
- 头像和特效

## 6. 非功能要求

- Windows Chrome 优先
- 2GB 以下视频必须给出明确限制或分段策略
- 长任务可取消
- 浏览器刷新后任务状态可恢复
- 所有处理保留源文件
- 失败任务可重试
- 导出结果具有确定性命名

## 7. MVP 验收

完整完成以下流程：

1. 新建“三国项目”
2. 新建“关羽”
3. 导入攻击正面 MP4
4. 按 12 FPS 抽帧
5. 删除多余帧
6. 去背景并修边
7. 统一为 256×256
8. 导出 16 帧 SpriteSheet
9. 导出 GIF
10. Unity 插件导入并生成可播放 Prefab
