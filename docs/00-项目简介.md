# 项目简介

## 产品名称

- 中文：灵画 AI
- 英文：SpriteForge AI
- 内部简称：SpriteForge

## 产品定位

SpriteForge 是面向独立游戏开发者和中小游戏团队的 AI 角色资源生产工作台。

它不以“生成一张图片”为终点，而以“导出可直接进入 Unity 的完整角色资源”为终点。

## 核心用户

### 独立 Unity 开发者

没有专职技术美术，需要快速完成角色序列帧、动画和 Prefab 配置。

### 中小游戏团队美术

需要批量处理动作视频、序列帧、透明背景和图集。

### 外包与换皮团队

需要统一角色规格、尺寸、帧率、方向、命名和导出格式。

## 核心问题

- 素材分散在多个工具中处理
- 视频抽帧后需要大量手工筛帧
- 去背景容易破坏角色内部黑色区域
- 每次改图都要重新在 Unity 里切片和配置动画
- 动作之间尺寸、位置、Pivot 不统一
- AI 生成结果无法直接进项目

## 产品价值

```text
传统：素材 → 多个工具 → 手工整理 → Unity 重复配置
SpriteForge：素材 → 工作区处理 → 一键导入 Unity
```

## 第一阶段成功标准

- 用户能在 10 分钟内把一段角色动作视频转换为 Unity 可播放 Prefab
- 不要求用户手写 JSON
- 不要求用户手动逐帧切 Sprite
- 导出结果可重复生成
- 参数可保存并复用
