# 序列帧编辑器

## 输入

- PNG/JPG/WebP 图片序列
- GIF
- WebP 动画
- MP4/WebM/MOV
- 已有 SpriteSheet

## 抽帧

- 目标 FPS：6/8/10/12/15/24/30/自定义
- 截取时间范围
- 最大帧数
- 等间隔抽取
- 场景变化抽取（后置）

## 帧操作

- 全选
- 反选
- 区间选择
- 禁用
- 删除
- 复制
- 拖动排序
- 自动去重
- 重命名

## 画布

- 128/256/512/1024
- 自定义尺寸
- 保持原比例
- 自动 Trim
- 固定角色脚底
- 自动居中
- 自定义 Pivot
- Padding
- Extrude

## 排列

- 自动接近正方形
- 固定列数
- 固定行数
- 横向长条
- 纵向长条
- 不满格允许透明空位

## 导出

- PNG SpriteSheet
- 独立帧 ZIP
- GIF
- WebP
- JSON 元数据
- Unity 描述文件
