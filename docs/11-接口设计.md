# 接口设计

MVP 本地优先，可将以下接口实现为前端 Service；云端化后保持协议不变。

## 项目

- `createProject(input)`
- `updateProject(id, patch)`
- `listProjects()`
- `deleteProject(id)`

## 角色

- `createCharacter(projectId, input)`
- `updateCharacter(id, patch)`
- `addAction(characterId, input)`
- `createActionVersion(actionId, settings)`

## 媒体

- `inspectMedia(file)`
- `extractFrames(file, settings)`
- `splitSpriteSheet(file, grid)`
- `buildSpriteSheet(frames, settings)`
- `buildPreview(frames, settings)`

## 图像处理

- `removeBackground(frame, settings)`
- `removeConnectedBlackBackground(frame, settings)`
- `decontaminateAlpha(frame, settings)`
- `stabilizeFrames(frames, settings)`

## 导出

- `buildExportManifest(characterId, selection)`
- `exportZip(manifest)`
- `validateManifest(manifest)`

## 任务状态

```ts
type TaskStatus =
  | "queued"
  | "running"
  | "success"
  | "failed"
  | "cancelled";
```
