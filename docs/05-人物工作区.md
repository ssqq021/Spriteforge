# 人物工作区

## 页面目标

围绕一个角色管理参考图、动作、方向、版本和导出状态。

## 布局

### 左侧

- 角色缩略图
- 动作分组
- 方向
- 版本
- 新增动作

### 中间

- 透明棋盘背景
- 缩放
- 平移
- 适应窗口
- 原点和 Pivot
- Onion Skin
- 播放控制

### 右侧

- 角色名称
- 类型
- 风格标签
- 默认尺寸
- 默认 FPS
- Pivot
- 一致性参考图
- 文件命名规则

### 底部

- 帧时间轴
- 启用/禁用
- 拖动排序
- 单帧时长
- 重复帧提示
- 前后帧差异提示

## 状态

- 未导入
- 待处理
- 处理中
- 已完成
- 处理失败
- 已导出
- 源文件已变化

## 关键交互

- 修改参数不立即覆盖产物
- 点击“应用处理”创建新版本
- 允许对比任意两个版本
- 导出引用明确版本
