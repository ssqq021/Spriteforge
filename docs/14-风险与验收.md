# 风险与验收

## 主要风险

### 范围过大

同时做生图、动画、市场、协作和 Unity 会导致无法发布。

应对：MVP 只完成“已有素材到 Unity”。

### AI 动画质量不可控

单图生成多动作仍存在角色变化、漂移和帧间闪烁。

应对：AI 作为可选输入，编辑和导出管线独立成立。

### 浏览器性能

大视频、高清帧和长序列可能导致内存不足。

应对：

- 限制输入
- 分批处理
- Worker
- 后续 Tauri

### 抠图破坏角色

简单按颜色去黑会删除头发、衣服和阴影。

应对：使用边界连通、主体保护和人工蒙版修正。

### Unity 兼容性

不同 Unity 版本 API 和导入行为可能变化。

应对：首发只承诺 Unity 2022.3 LTS 与 Unity 6。

## 发布门槛

- 5 个不同风格角色
- 每个至少 3 个动作
- 3 种输入方式
- 100 次导出无数据丢失
- Unity 导入成功率 ≥ 95%
- 失败时有可理解错误
- 不覆盖源素材
