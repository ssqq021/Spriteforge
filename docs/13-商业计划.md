# 商业计划

## 建议切入点

不要一开始售卖“AI 生成人物”。

先售卖：

> 更快地把角色动画素材变成 Unity 可用资源。

这是更明确、更容易验证的付费需求。

## 产品形态

### 免费 Web 工具

- 视频抽帧
- 帧筛选
- 基础 SpriteSheet
- GIF 预览
- 本地处理

目标：获客和建立口碑。

### Pro 桌面版

- 大文件
- 批处理
- 高质量背景处理
- 角色稳定
- 导出模板
- Unity 一键导入

建议一次性买断或低价订阅。

### AI Credits

只对高成本能力按量收费：

- 动作生成
- 超分辨率
- 插帧
- 一致性生成
- 多方向生成

## 定价实验

- Web：免费
- Pro 早鸟：US$29–49 买断
- Pro 正式：US$9–15/月
- Studio：US$29–49/月
- AI：Credits

不要在没有真实用户前承诺“无限生成”。

## 获客渠道

- Unity Asset Store
- itch.io 工具区
- Reddit r/Unity2D
- Indie Hackers
- Product Hunt
- GitHub
- 中文独立游戏社群
- 视频教程

## 第一阶段验证问题

- 用户每周处理多少个动作？
- 最大痛点是抽帧、抠图、对齐还是 Unity 配置？
- 他们是否愿意为 Unity 自动导入付费？
- 他们希望网页、本地桌面还是 Unity 插件？
- 哪种素材来源最多：AI 视频、绿幕视频、PNG 序列还是 Spine 导出？
