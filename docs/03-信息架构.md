# 信息架构

## 一级导航

```text
首页
人物
动画
序列帧
AI 修图
项目
Unity 导出
任务记录
设置
```

MVP 不展示 UI 素材、Tile、市场和云端资源，避免空功能占据导航。

## 首页

- 快速创建
- 最近项目

## 项目

- 项目列表
- 新建项目

- 左侧：角色及动作
- 中间：预览画布
- 右侧：当前对象参数
- 底部：帧时间轴
