# 开发计划

## 总体策略

第一版不以 AI 动作生成为核心。先用现有能力建立 Unity 闭环，再逐步增加 AI。

## Sprint 0：工程整理

- 盘点 lunghwa-media-tools
- 统一 TypeScript 类型
- 拆分媒体、帧、导出模块
- 建立测试样本
- 建立性能基线

## Sprint 1：项目与角色

- 首页
- 项目 CRUD
- 角色 CRUD
- IndexedDB
- 最近项目
- 自动保存

## Sprint 2：人物工作区

- 三栏布局
- 动作列表
- 帧时间轴
- 预览播放
- FPS 与 Loop
- 版本概念

## Sprint 3：序列帧编辑器

- 迁移视频抽帧
- 迁移帧筛选
- 迁移 SpriteSheet
- GIF/WebP
- 布局与命名统一

## Sprint 4：图像清理

- 连通黑底移除
- 主体保护
- Alpha 去污染
- 前后对比
- 批处理

## Sprint 5：Unity 导出

- JSON Schema
- ZIP 目录
- Unity Editor Window
- 自动切片
- AnimationClip
- Animator
- Prefab
- 导入报告

## Sprint 6：测试发布

- 5 套角色样本
- Unity 2022.3
- Unity 6
- Windows Chrome
- 错误收集
- 使用教程
